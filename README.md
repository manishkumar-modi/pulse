# 🫀 Pulse

An automated appointment and reminder application that helps businesses
schedule services and notify customers at the right time.

------------------------------------------------------------------------

## 📘 Project Description

Pulse is a smart scheduling and reminder platform designed to help
businesses streamline their appointment flow. It automates booking,
reduces no-shows with timely notifications, and provides a unified
structure for managing services and customers.

### ⭐ Key Features

- Create and manage customer appointments
- Automated reminders (SMS/Email depending on integration)
- Manage business profiles and service types
- Clean and consistent API responses
- Extensible architecture built using Spring Boot
- Database-backed (JPA/Hibernate)
- Designed for scalability and maintainability
